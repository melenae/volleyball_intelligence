# Определения аналитических показателей

Реализация: `app/analytics/team.py`. Критерии корректного матча — [match-result-validity.md](./match-result-validity.md).

## Источник данных

Все показатели считаются только по строкам PostgreSQL (матчи и сеты). Seed и HTTP не являются источником расчёта.

## Множество учитываемых матчей

В статистику команды входят только **корректные завершённые матчи**, в которых команда — хозяин или гость. Проверка — `evaluate_match_result` (`app/services/match_result.py`).

Не входят:

- `scheduled`, `cancelled`;
- `completed` с неполным или противоречивым результатом сетов (включая ничью по выигранным сетам).

## Метрики команды

Для выбранной команды и опционального фильтра `season_id`:

| Показатель | Определение |
|------------|-------------|
| `played_matches` | число корректных завершённых матчей команды |
| `wins` | матчи, где команда выиграла больше сетов |
| `losses` | матчи, где соперник выиграл больше сетов |
| `sets_won` | сумма выигранных сетов команды в учитываемых матчах |
| `sets_lost` | сумма проигранных сетов |
| `points_for` | сумма очков команды по всем сетам учитываемых матчей |
| `points_against` | сумма очков соперников в тех же сетах |
| `win_percentage` | `null`, если `played_matches = 0`; иначе `wins / played_matches * 100` |
| `match_timeline` | учитываемые матчи в хронологическом порядке (`scheduled_at`, затем `match_id`) |

Очки — **записанный** счёт сета, без пересчёта по правилам FIVB.

## Dashboard

- `matches_total` — все матчи сезона (любой статус).
- `matches_valid_completed` — матчи сезона с `is_valid_completed_match = true`.
- `standings` — метрики каждой команды по **одной** выборке матчей сезона (без N+1 запросов на команду).
- `recent_matches` — до 5 последних матчей сезона по дате (включая запланированные).

## Игрок

Индивидуальные матчевые показатели (эйсы, атаки, личные победы) **не** рассчитываются без `MatchEvent`. API игрока возвращает составы (`rosters`) и пояснение.

## Происхождение данных

Аналитические ответы API содержат `data_origin: "demo"` для демонстрационной лиги.

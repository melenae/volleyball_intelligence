# Placeholder: адаптер AVL

Реальной интеграции с AVL в репозитории **нет**: нет HTTP-клиента, токенов, URL и парсинга сайта.

Код-заглушка: `apps/api/app/ingestion/avl/` (интерфейс без реализации).

## Что потребуется от владельца AVL

1. **Контракт API**: базовый URL, версия, OpenAPI или примеры ответов.
2. **Аутентификация**: тип (API key, OAuth2, mTLS), срок жизни токенов, отдельные sandbox/production.
3. **Идентификаторы**: стабильные внешние id для лиги, сезона, команды, игрока, матча; правила сопоставления с нашими `ref`.
4. **Модель матча**: статусы, часовой пояс `scheduled_at`, формат счёта по сетам, отмены и переносы.
5. **Составы**: привязка игрока к команде в сезоне, номер на майке.
6. **Ограничения**: rate limits, пагинация, условия использования и хранения данных.
7. **Юридическое**: разрешение на копирование данных в нашу PostgreSQL и отображение в продукте.

После получения контракта адаптер реализует `ImportDataSource` и передаёт нормализованный пакет в тот же strict writer, что и JSON v1.

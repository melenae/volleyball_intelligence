# Правила для агента

Этот файл описывает договорённости репозитория Volleyball Intelligence. Перед изменением `apps/web` дополнительно прочитай `apps/web/AGENTS.md`: там указаны отличия установленной версии Next.js.

## Границы фаз

Не перескакивай через фазу. Phase 1 — каркас, health и прокси. Модели, миграции, аналитика, seed и страницы команд, игроков и матчей начинаются только после отдельного подтверждения.

Не выдумывай URL, поля и авторизацию AVL. Внешний источник остаётся заглушкой, пока владелец платформы не передаст контракт.

Не помечай работу готовой, пока соответствующие команды не выполнены. Если команда не запустилась, сообщи об этом и причину.

Коммит и push делай только по явной просьбе.

## Архитектура

Модульный монолит: `apps/web` и `apps/api`. PostgreSQL — источник данных для экранов. Адаптеры импорта только записывают в каноническую модель.

Бизнес-правила не размещай в React-компонентах и HTTP-обработчиках. SQL не размещай во frontend. Ответы API описывай Pydantic-схемами, не возвращай объекты SQLAlchemy напрямую.

Внутренний первичный ключ — UUID. Секреты только в переменных окружения. `.env` не коммитится.

Интерфейс и документация на русском. Имена в коде на английском.

CORS ограничен списком `CORS_ORIGINS`. Не открывай `*` и не включай credentials без отдельного решения.

## Подтверждённые правила предметной области

Подробности: `docs/decisions/0001-confirmed-architecture.md`.

- У матча всегда есть `home_team` и `away_team`. Пустой `venue` допустим и означает нейтральную площадку.
- Победитель определяется по сетам. Неполный или противоречивый результат не получает победителя и не входит в статистику завершённых корректных матчей.
- Seed demo-данных идемпотентен: повторный запуск не создаёт дубликаты.
- Личные действия игрока не выдумываются, пока нет событий матча.
- Показатели demo-лиги помечаются `data_origin: "demo"`.

## Проверки

Backend из `apps/api`:

```powershell
uv run ruff check .
uv run ruff format --check .
uv run pytest
```

Frontend из `apps/web`:

```powershell
npm run lint
npm run typecheck
npm run build
```

Полный локальный стек: `docker compose up --build` из корня, затем `GET /api/v1/health` напрямую и через `http://localhost:3000/api/v1/health`.
